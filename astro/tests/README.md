>*Test the `Astro` library packages*

This folder contains AUnit tests for all the pakages in the Astro library.

***Warning***

Some of tests are not implemented in this version. These tests are included as
placeholders for future enhancements,

---
## Build

Use Alire to compile and build the tests:

```sh
cd tests
alr build
```

---
## Run the tests

Run the tests using Alire:

```sh
alr run
```
