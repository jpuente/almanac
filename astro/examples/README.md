>*`Astro` library example*

This folder contains examples of how to use the Astro library.

The following examples are available:

- **Sun tracker**  
A simple program to print the position of the Sun in spherical and horizontal
coordinates at a given location and time.

---
## Build

Use Alire to compile and build the example:

```sh
cd examples
alr build
```

---
## Run the example

Run the example using Alire:

```sh
alr run
```
